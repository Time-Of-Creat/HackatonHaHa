# DATA MATCH. Технический трек. Решение.

Презентация лежит в файле "Презентация.pptx"

## Запуск программы - требования

 * Python 3.10.x (рекомендуемая версия)
 * Установка всех библиотек (находятся в файле "requirements.txt", установить через pip install -r requirements.txt)
 * Jupyter notebook (файл юпитера - "Графики.ipynb")
 * Таблицы с данными, предложенными хакатоном, помещать вручную в корень проекта в папку data

## При запуске через Jupyter notebook

Согласно требованиям хакатона был приложен файл Jupyter notebook, демонстрирующий работу программы.

Код разбит на три блока:
1. Обучение нейросети и валидация
2. Предсказания по продажам билетов, визуализация в виде столбчатой диаграммы для каждого матча отдельно
3. Формирование таблицы предсказаний - таблица сформируется в виде csv - файла в корне проекта (название: predictions.csv)

## При запуске через python напрямую

Если нужно запустить программу через python, то для этого потребуется запустить модуль source.main. Рабочей директорией при запуске является корень проекта.
Запуск программы через консоль:
python -m source.main
